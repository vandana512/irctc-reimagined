# 🚆 IRCTC-Reimagined

Reimagining the Indian Railway booking experience — a modern, intuitive, and accessible redesign of the **IRCTC** platform .  

> “Making travel booking simpler, smarter, and more inclusive.”

## 🌟 Overview  

**IRCTC-Reimagined** brings a fresh, user-centric approach to the Indian Railway ticketing system.  
This prototype focuses on **modern UI/UX**, **real-time interactivity**, and **AI assistance** — all wrapped in a clean, accessible web experience.

### 🎯 Objectives:
- Simplify the **ticket booking process**
- Enable **inclusive and regional access**
- Introduce **AI assistance** for smoother navigation
- Provide a **lite, ad-free mode** for low-bandwidth users

---

## 🧩 Features

### 🚉 Core Functionalities
- **Real-Time Seat & Fare Updates**  
  Instant seat and fare changes (mock data / API-ready design).  

- **Clean Booking Interface**  
  Streamlined search and booking flow for faster interactions.  

- **Responsive Layout**  
  Optimized for desktop, tablet, and mobile screens.  

---

### 🤖 Smart Enhancements

- **AI Assistant (Voice + Regional)**  
  - Floating chat icon (bottom-right corner).  
  - Opens a small chatbot window (rule-based/dummy Q&A).  
  - Future-ready for multilingual voice and regional assistance.  

- **Lite Mode (Ad-Free)**  
  - “⚡ Switch to Lite Mode” button toggles a **minimal interface** — booking form + results only.  
  - Perfect for low-speed networks or simpler usage.  

- **Accessible Design**  
  - WCAG-friendly typography and color contrast.  
  - Keyboard navigation and screen-reader compatibility.  
  - Designed for comfort across all user groups.
